## Gotchas learned

- `pgrep -f`/`pkill -f` with the pattern in your own command line kills
  your shell (exit 144): use `pgrep -f "[V]sim_top"`-style patterns.
- Sun OBP with no NVRAM image: "Incorrect configuration checksum",
  diag-switch? true, a full 464 MB memory test (~2 min at 1-2.5 MB/s),
  then a network boot. Stop-A is `misterkvms-cli key ralt+f1+a --hold
  300`; then `boot disk`.
- Solaris CDE login: the mouse ignores its first ~48 packets after X
  starts (send ~60 tiny moves first); Motif's Meta is the Win key; the
  Delete/Backspace keys did not erase in dtlogin's field; Options ->
  Command Line Login (mouse) gives a console; root has no password.
- Under OpenBIOS with Display = Serial console, Solaris's console is
  ttya: log in there (`printf "root\r" > /dev/ttyS1` on the MiSTer,
  capture with `cat /dev/ttyS1`), and X still comes up on the TCX.
- `osd_load.sh` checks the rbf path with ps: compare the MiSTer pid
  before and after to be sure it reloaded.
